# ADR 0004: MVP 与优秀版本分阶段交付边界

## 状态

已采纳（Accepted）

## 上下文

团队目标是先交付“稳定可恢复的热管理基础能力”，再逐步扩展高级分析功能。若一开始同时追求全部高级特性，容易导致权限、传感器兼容与安全回退测试不足。

## 决策

1. 采用两阶段交付：
   - **MVP**：机型识别、监控、智能控制、静音/均衡/性能三模式、安全回退、睡眠唤醒恢复、一键恢复默认、菜单栏常驻。  
   - **优秀版本**：自定义曲线、功耗感知细化、App 触发策略增强、历史图、降频深度监测、配置导入导出、CLI 细化。  
2. 高级功能排除于初版范围：远程监控、机器学习自学习、按时间段模式切换、合盖专用策略。  

## 影响

- 缩短 MVP 上线周期。  
- 保持首版控制策略闭环可验证、可回退。  
- 将复杂功能前移到第二阶段，降低首版风险。
