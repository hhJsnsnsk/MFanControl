# ADR 0001: Apple Silicon 优先与无风扇机型只读策略

## 状态

已采纳（Accepted）

## 上下文

本项目定位为 Apple Silicon 热管理系统，而不是通用风扇控制器。不同芯片与机型的 SMC key、传感器语义、以及风扇控制能力差异很大；若兼容 Intel 或尝试在无风扇机型下“兼容展示”，会引入不可控误差。

项目目标是提供可解释、稳定且安全的自动化控制，因此必须在启动时明确当前硬件边界，并避免把风扇控制暴露到不支持的能力上。

## 决策

1. 本项目第一优先级仅支持 **Apple Silicon（M1+）**。  
2. 对非 Apple Silicon 机型：直接进入“暂不支持”路径，展示明确提示，并不提供控制入口。  
3. 对检测到“无风扇”能力机型（如相关 MacBook Air 平台）：显示“该设备不可控”并固定为只读/系统默认控制状态，不展示手动调速、模式切换等控制动作。

## 影响

- 设计更清晰：把“是否可控”放在能力识别前置，避免用户误以为能生效。  
- 范围收敛：减少跨架构适配和故障面，提升发布稳定性。  
- 文案和交互一致：遇到不可控场景时，主张透明、直接，不做虚假控制或静默失败。  
- 对上游扩展约束明确：未来若要支持 Intel，需要独立 ADR 评估。
