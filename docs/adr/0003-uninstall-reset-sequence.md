# ADR 0003: 卸载流程先恢复 Apple 默认控制

## 状态

已采纳（Accepted）

## 上下文

风扇控制属于高风险硬件操作。用户卸载或清理程序时，如果未明确恢复 macOS 默认策略，可能导致系统留在上次写入状态，形成不可预期行为。  

本项目强调安全可恢复与可审计，因此卸载行为需要有可验证的收尾流程，而不能仅删除组件。

## 决策

在卸载路径执行以下固定序列：

1. 引导用户先执行“恢复 Apple 默认控制”。  
2. 在删除特权 helper 之前，再次执行一次默认控制恢复动作。  
3. 清理启动项与 XPC 注册。  
4. 清理本地配置与缓存（可选择保留配置导出快照）。  
5. 卸载/退出前执行最终状态回退校验。  

## 影响

- 保证卸载不会留下不完整控制状态。  
- 降低硬件控制遗留导致的异常风险。  
- 为审计和问题定位提供清晰恢复链路。  
- 与安全优先原则一致：先收尾恢复，再移除组件。
